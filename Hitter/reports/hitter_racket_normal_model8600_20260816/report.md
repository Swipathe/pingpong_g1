# HITTER model_8600 拍面法向指标变化

## 技术摘要

- 拍面法向指标在训练早期快速改善：第 0–99 轮的余弦等效角约为 **41.84°**，第 500–999 轮降至 **15.24°**。
- 最好的连续 100 轮出现在第 **759–858** 轮，余弦等效角为 **14.38°**；单点最好值出现在第 777 轮，为 **13.80°**。
- 此后指标发生回退：第 5000–5999 轮升至 **20.98°**，停训前最后 500 轮为 **19.94°**，最后 100 轮为 **19.90°**。
- 与第 500–999 轮相比，最后 500 轮原始误差从 **0.03518** 增至 **0.05993**，增加 **70.36%**；余弦等效角增加 **4.69°**。
- 末段并非持续恶化：约第 5000–6000 轮达到约 **21°** 后，后续缓慢恢复到约 **20°**，但没有回到第 500–1000 轮的最好水平。
- `Episode_Reward/racket_ori` 在中后期保持约 **0.97–1.00**，对这段角度回退不敏感；仅看 orientation reward 会低估法向误差的变化。

按保存配置的 `std=0.45` 代入奖励公式，早期稳定误差和末段误差对应的理论即时奖励仅从约 **0.994** 降至 **0.982**，相差约 **1.15 个百分点**。因此原始法向误差增加 70% 时，奖励曲线看起来仍然接近满分。

## 指标定义

TensorBoard tag：

```text
Metrics/motion/hitter_strike_racket_ori_error
```

源码计算：

```text
alignment = dot(带符号的实际击球面法向, 目标球拍速度单位方向)
error = 1 - alignment
```

这次配置中 `racket_orientation_use_abs_normal_alignment=false`，因此正反法向不会被视为等价。误差越接近 0 越好；0 表示完全同向，1 表示相差 90°，2 表示完全反向。

报告中的“余弦等效角”按以下公式换算：

```text
theta_equiv = arccos(1 - error)
```

## 数据与方法

- 数据源为该完整 run 的唯一 TensorBoard event 文件，共 **8,624** 条 scalar，step 从 **0** 到 **8623** 严格连续。
- 未发现重复 step、缺失 step、NaN 或训练重启造成的 step 重叠。
- 主要比较采用连续 500 轮均值；同时检查最后 100 轮、最后 1000 轮和 100 轮滚动均值。
- 最后 100、500、1000 轮分别约为 **19.90°、19.94°、20.04°**，说明“停训前约 20°”对窗口选择不敏感。

## 限制与不确定性

- TensorBoard 中保存的是聚合后的 `1-cos(theta)`。对聚合误差做反余弦得到的是“余弦等效角”，不是逐环境真实角度的精确算术平均。
- 当前 event 只提供正手和反手合并后的 scalar，无法判断回退主要来自正手还是反手。
- Orientation reward 使用 `std=0.45` 的指数奖励，并在中后期接近饱和；它不能代替原始法向误差进行模型选择。
- 拍面法向指标最好不代表 policy 综合表现最好。选择 checkpoint 时还需要同时检查击球位置、球拍速度、终止率和真机可执行性。

## 建议

1. 如果拍面法向是当前首要目标，重点离线比较 `model_800`、`model_900`、`model_1000` 与 `model_8600`，而不是默认最后权重最好。
2. 在评估脚本中分别统计正手和反手的实际角度分布，至少报告均值、P50、P90 和大于 30° 的比例。
3. 若继续训练，可适当减小 orientation reward 的 `std` 或增加原始角度指标约束，使 15° 到 20° 的回退在奖励上更明显；修改前应同时检查它与位置、速度奖励的权衡。
