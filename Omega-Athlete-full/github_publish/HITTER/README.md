# HITTER

This repository snapshot contains the HITTER Isaac/MOSAIC training code and the RobotBridge2 deployment stack.

Included:

- `HITTER-main/`: IsaacLab/RSL-RL training, play scripts, HITTER task code, robot assets, reference HITTER motions, and the packaged `hitter_m20400` checkpoint.
- `RobotBridge2/`: deployment code, HITTER configs, robot assets, Unitree SDK2, and the default HITTER ONNX model.

Large generated training logs, raw captures, SwanLab backups, and bulk motion datasets are intentionally excluded from this GitHub copy.
